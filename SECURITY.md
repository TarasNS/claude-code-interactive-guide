# Security

## Reporting a vulnerability

If you discover a security vulnerability in Claude Engineering Lab, please report it **immediately** to:

**Head of IT & Digitalization**

Do not open a public issue, do not discuss it in pull requests, and do not delay.

Include:
- A description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if you have one)

The Head of IT & Digitalization will engage the CPIO (Chief Privacy and Information Officer) as needed and coordinate the response.

## Security contact

- **Role:** Head of IT & Digitalization
- **Organization:** Nordic Solar

All security questions and concerns should go to this contact, not to individual engineers or GitHub issues.
